# Portfolio — Donatien Fofana

Portfolio personnel. Étudiant MIAGE, futur consultant ERP / systèmes d'information.

**Stack :** Next.js 14 · TypeScript · Tailwind CSS · rendu statique.

## Démarrage rapide
```bash
npm install
npm run dev      # http://localhost:3000
```

## Structure
- `data/` — tout le contenu éditable (profil, projets, compétences, certifs…)
- `app/` — pages (accueil + études de cas `/projets/[slug]`)
- `components/` — composants réutilisables (nav, footer, utilitaires)
- `public/` — images (photo, futures captures)

👉 Voir **GUIDE.md** pour tout : modifier le contenu, ajouter une certif, déployer sur Vercel.
